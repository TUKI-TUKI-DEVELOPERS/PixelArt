# Mi Ángel Guardián — Madre adulto micro-piloto

Paquete específico para probar la versión adulta memorial/protectora `Mi Ángel Guardián — Madre`.

## Dirección

- Libro específico: `Mi Ángel Guardián — Madre`.
- Familia artística: `refugio maternal de luz`.
- Cobertura: 2 hijo adulto → madre, 2 hija adulta → madre.
- Dimensión de generación aprobada para pilotos: `1600x944`.
- Formato preferido de salida: `WebP`.

## Reglas

- Dedicante con rostro visible frontal o tres cuartos.
- Madre como pieza artística protectora grande/protagonista, basada en la foto real y preservando parecido.
- No foto pequeña, no fantasma literal, no ángel literal, no halo, no alas humanas.
- Poemas rimados, castellano neutral, sin voseo.
- Sin mascotas/animales.
