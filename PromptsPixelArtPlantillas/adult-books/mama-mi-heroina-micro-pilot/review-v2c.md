# Revisión v2c — Mamá, Mi Heroína adulto micro-piloto

## Cambio aplicado

Regeneración de v2b con una regla editorial adicional: el título no usa dorado fijo en todas las plantillas. Cada título toma un color temático acorde al arquetipo y escena.

Paletas usadas:

1. Arquitecta — bronce arquitectónico / champán / cobre.
2. Capitana — marfil de faro / azul petróleo / turquesa apagado.
3. Alquimista — ámbar / cobre / verde salvia.
4. Jardinera — verde salvia / crema cálido / dorado musgo.

También se mantiene la regla de apodo variable:

1. Inicio: `Para Mamá Elena, ...`
2. Medio: `Hoy, Mamá Elena, ...`
3. Final: `... a ti, Mamá Elena.`
4. Medio: `tu amor, Mamá Elena, ...`
