# Auditoría — Aventuras Entre Patas adulto micro-piloto

## Riesgos y mitigaciones

| Riesgo | Mitigación |
|---|---|
| Que adulto se vuelva serio genérico | Cada plantilla tiene arquetipo, escenario, objeto y magia propios. |
| Que todas las escenas parezcan iguales | Los 4 conceptos usan mundos visuales distintos. |
| Que todos los títulos se vean iguales | Color editorial temático por plantilla; no dorado fijo. |
| Que todos los poemas suenen iguales | Ubicación variable del apodo/nombre principal. |
| Que el texto caiga en el pliegue | Franja central prohibida y márgenes de seguridad. |
| Que el concepto sea infantil | Metáforas adultas, escenas premium y magia conceptual contenida. |
| Que todas las escenas sean interiores/sentadas | Micro-piloto v2 exige variedad espacial: exterior, movimiento, escala o acción emocional; no más de una escena tipo mesa/sala. |
