# Papá, Mi Héroe — Micro-piloto adulto

Objetivo: validar tono, poema, prompt e imagen para la versión adulta antes de producir las 40 plantillas.

Alcance inicial:

- 2 plantillas de hijo adulto → papá.
- 2 plantillas de hija adulta → papá.
- Sin generación de imágenes hasta aprobación de textos, prompts y presupuesto.
- Dimensión definida para el micro-piloto: `1600x944`, igual que las imágenes actuales de plantillas.

## Archivos

| Archivo | Uso |
|---|---|
| `audit.md` | Auditoría del libro infantil existente y riesgos del adulto. |
| `cost-estimate.md` | Presupuesto micro-piloto y libro completo interior. |
| `pilot-templates.md` | 4 plantillas adultas propuestas con poemas y campos de prompt BD. |
| `images/` | Reservado para resultados cuando el presupuesto esté aprobado. |
| `generation-prompts.md` | Prompts completos usados para las imágenes de preview. |
| `review.md` | Resultado de generación inicial, costo real y revisión interna. |
| `generation-prompts-v2.md` | Prompts ajustados con poemas mejorados y casa bajo poema. |
| `review-v2.md` | Resultado de generación v2, costo real y revisión interna. |
| `generation-prompts-v3.md` | Prompts ajustados al estilo libro abierto del catálogo actual. |
| `review-v3.md` | Resultado de generación v3, costo real y revisión interna. |

## Nombres de preview

- Papá destinatario: `Papá Leo`.
- Hijo adulto: `Mateo`.

Estos nombres son solo para imágenes estáticas de ejemplo. Las plantillas reales conservan placeholders para datos del cliente.
