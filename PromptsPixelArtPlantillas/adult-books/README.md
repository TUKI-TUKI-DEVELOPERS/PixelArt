# Adult Books Workbench

> **Fuente vigente:** [`../CURRENT_TEMPLATE_PROGRAM.md`](../CURRENT_TEMPLATE_PROGRAM.md). Si este directorio contiene un README, piloto o reporte con una afirmación distinta de “aprobado”, “final” o “vigente”, prevalece el programa vigente.
>
> **Generación pagada pausada:** no escalar imágenes hasta consolidar prompts durables y archivar el material histórico según el programa vigente.

Espacio de trabajo para versiones adultas antes de integrarlas a la BD/app.

Cada libro debe tener un subdirectorio con:

```txt
<libro>-micro-pilot/
├── README.md
├── audit.md
├── pilot-templates.md
├── cost-estimate.md
└── images/              # solo cuando el presupuesto esté aprobado
```

No generar imágenes hasta que `audit.md`, `pilot-templates.md` y `cost-estimate.md` estén aprobados.
