# Micro-piloto adulto — El Mejor Equipo

Objetivo: preparar 4 plantillas adultas para `El Mejor Equipo` antes de escalar el libro completo.

Este paquete sigue el estándar aprobado en `Mamá, Mi Heroína Adulto v2c`:

1. Arquetipo adulto diferenciado por plantilla.
2. Escenario y objeto símbolo únicos.
3. Magia conceptual propia, no solo partículas doradas.
4. Color de título acorde al tema; no dorado fijo.
5. Ubicación variable del apodo/nombre en el poema.
6. Tono adulto, familiar, sano y no romántico cuando aplique.
