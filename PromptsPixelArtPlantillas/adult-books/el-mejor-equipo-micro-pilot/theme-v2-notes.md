# Ajuste temático v2 — El Mejor Equipo adulto

La prueba visual fue buena, pero el usuario observó una tendencia general: en adultos estamos cayendo demasiado en salas, mesas o personajes sentados.

## Regla nueva

Adulto no debe significar interior estático. Para el escalado completo de `El Mejor Equipo`, mantener los arquetipos aprobados pero llevar más plantillas a escenas con movimiento, exterior y escala.

## Cómo reinterpretar el piloto

| Piloto v1 | Para versión completa |
|---|---|
| Sala de estrategia secreta | Azotea/ciudad nocturna con misión compartida, mapa proyectado y hermanos de pie. |
| Taller de soluciones imposibles | Hangar, puente en construcción o taller abierto con acción corporal, no todos sentados. |
| Puente que siempre cruzamos | Mantener: ya tiene exterior, movimiento y escala. |
| Banda sonora de nuestras batallas | Concierto de azotea, calle nocturna musical o ensayo con movimiento, no solo sofá/estudio. |

## Checklist para full generation

- [ ] Máximo 1 escena de mesa/sala por set de 4.
- [ ] Al menos 2 escenas exteriores o semi-exteriores.
- [ ] Al menos 2 escenas con personajes caminando, construyendo, cruzando o actuando.
- [ ] Mantener apodo grupal variable y color de título temático.
- [ ] Mantener restricción `sin mascotas/animales`.
