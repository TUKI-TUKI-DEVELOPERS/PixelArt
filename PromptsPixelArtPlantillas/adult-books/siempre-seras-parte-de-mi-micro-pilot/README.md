# Siempre serás parte de mí adulto micro-piloto

Corrección de alcance: este libro es de **hermanos**.

No es para mamá, papá, abuelo ni abuela. No debe resolverse con retratos artísticos de permanencia. La lógica correcta es mostrar a ambos hermanos juntos, usando las dos fotos subidas, en escenas vivas de memoria compartida.

## Dirección

- Libro específico: `Siempre serás parte de mí`.
- Relación: hermanos.
- Familia visual: `hermandad en escenas vivas`.
- Cobertura piloto: 2 hermano adulto → hermano, 2 hermana adulta → hermano.
- Dimensión de generación aprobada para pilotos: `1600x944`.
- Formato preferido de salida: `WebP`.

## Reglas

- Ambos hermanos con rostro visible frontal o tres cuartos.
- El hermano recordado aparece como persona en acción compartida, no como retrato/objeto.
- No foto pequeña, no retrato artístico, no fantasma literal, no ángel literal.
- No asumir padre/madre/abuelo/abuela/pareja.
- Poemas rimados, castellano neutral, sin voseo.
- Sin mascotas/animales.
