# Auditoría — Siempre en mi corazón adulto micro-piloto

## Riesgos y mitigaciones

| Riesgo | Mitigación |
|---|---|
| Confundir categoría con libro | Este paquete es solo para `Siempre en mi corazón`. |
| Que el recuerdo se vuelva fúnebre/morboso | Usar memoria luminosa, objetos, paisaje, cartas, fotos y símbolos; no dramatización. |
| Que aparezcan fantasmas literales | Prohibir fantasmas literales y apariciones sobrenaturales. |
| Que todas las escenas sean interiores/sentadas | Usar exteriores, rutas, cielo, estaciones, movimiento y escala. |
| Que todos los títulos se vean iguales | Color editorial temático por plantilla; no dorado fijo. |
| Que todos los poemas suenen iguales | Ubicación variable del apodo/nombre. |
| Que el modelo agregue mascotas | Prohibir mascotas, perros, gatos, aves y animales; este no es libro de mascotas. |
| Que el texto caiga en el pliegue | Franja central prohibida y márgenes de seguridad. |
