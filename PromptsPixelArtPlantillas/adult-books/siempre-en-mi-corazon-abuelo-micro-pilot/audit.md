# Auditoría — Siempre en mi corazón — Abuelo adulto micro-piloto

## Riesgos y mitigaciones

| Riesgo | Mitigación |
|---|---|
| Mezclar abuelo y abuela | Este paquete es solo `Abuelo Ricardo`; la abuela va en otro libro. |
| Que el recuerdo se vuelva fúnebre/morboso | Usar memoria luminosa, paisaje, objetos, cartas, fotos y símbolos vivos. |
| Que aparezcan fantasmas literales | Prohibir fantasmas literales y apariciones sobrenaturales. |
| Que todas las escenas sean interiores/sentadas | Usar costa, ruta, jardín y cielo abierto. |
| Que todos los títulos se vean iguales | Color editorial temático por plantilla; no dorado fijo. |
| Que todos los poemas suenen iguales | Ubicación variable de `Abuelo Ricardo`. |
| Que el modelo agregue mascotas | Prohibir mascotas, perros, gatos, aves y animales. |
| Que no se note la foto del abuelo | Exigir retrato/foto visible, reconocible y emocionalmente relevante; debe justificar la foto subida por el cliente. |
| Dedicante de espaldas / rostro no usado | Exigir rostro visible frontal o tres cuartos para el cliente/dedicante. Prohibir espalda, silueta y rostro oculto. |
| Memorial plano / foto literal sin arte | Definir familia artística por libro y tratamiento por plantilla, preservando parecido y evitando foto pequeña o fantasma literal. |
| Que el texto caiga en el pliegue | Franja central prohibida y márgenes de seguridad. |
