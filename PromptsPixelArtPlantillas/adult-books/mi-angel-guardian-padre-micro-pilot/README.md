# Mi Ángel Guardián — Padre adulto micro-piloto

Paquete específico para probar la versión adulta memorial/protectora `Mi Ángel Guardián — Padre`.

## Dirección

- Libro específico: `Mi Ángel Guardián — Padre`.
- Familia artística: `cartografía protectora de luz`.
- Cobertura: 2 hijo adulto → padre, 2 hija adulta → padre.
- Dimensión de generación aprobada para pilotos: `1600x944`.
- Formato preferido de salida: `WebP`.

## Reglas

- Dedicante con rostro visible frontal o tres cuartos.
- Padre como pieza artística protectora grande/protagonista, basada en la foto real y preservando parecido.
- No foto pequeña, no fantasma literal, no ángel literal, no halo, no alas humanas.
- Poemas rimados, castellano neutral, sin voseo.
- Sin mascotas/animales.
