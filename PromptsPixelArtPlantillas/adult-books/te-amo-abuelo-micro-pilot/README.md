# Micro-piloto adulto — Te amo, abuelo

Objetivo: validar 4 plantillas adultas para `Te amo, abuelo` antes de escalar el libro completo.

Este paquete ya incorpora los aprendizajes aprobados en `Mamá, Mi Heroína Adulto`:

1. Arquetipo adulto diferenciado por plantilla.
2. Escenario y objeto símbolo únicos.
3. Magia conceptual propia, no solo partículas doradas.
4. Color de título acorde al tema; no dorado fijo.
5. Ubicación variable del apodo en el poema.
6. Tono adulto, familiar, sano y no romántico.
