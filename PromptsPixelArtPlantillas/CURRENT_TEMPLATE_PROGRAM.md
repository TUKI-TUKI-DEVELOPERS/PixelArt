> **Estado: consolidación previa a generación.** No generar, subir a MinIO, modificar SQL, manifest ni producción hasta que este programa tenga prompts durables aprobados por libro y se cierre la QA visual del lote de Papá.

## Reglas no negociables

1. Cada libro conserva **20 plantillas**: se reemplazan cinco, no se agregan nuevas.
2. Todos los protagonistas deben verse a escala significativa, con rostro nítido, frontal o en tres cuartos. No usar personas de espaldas, diminutas ni tapadas.
3. La magia debe ser la acción o el mundo imposible de la escena. Luces y partículas decorativas no bastan.
4. Perú se representa mediante prácticas y situaciones vivas, no monumentos ni postales turísticas.
5. En libros memoriales, la persona recordada aparece tangible, reconocible y participando junto a su familiar. Nunca se representa mediante un cuadro, álbum, retrato, fotografía enmarcada, silla vacía, objeto sustitutivo, fantasma, transparencia, halo o alas humanas.
6. Las referencias externas sirven solo para dirección emocional; no se usan personajes, nombres, marcas, logotipos, uniformes, escenas ni estilos protegidos.
7. Para las previews estáticas actuales: arte plano a sangre completa, sin libro físico, páginas, lomo, marcos ni mockups. El texto se compone localmente, no mediante el modelo de imagen.
8. El apodo del destinatario rota por plantilla: **inicio → medio → final**, repitiendo el ciclo. El título, poema, separadores y ornamentos se componen determinísticamente.

## Procedimiento obligatorio antes de gastar en imágenes

1. Escribir los prompts completos de las cinco sustituciones en una fuente durable por libro, usando esta matriz.
2. Revisar que cada prompt cumpla las reglas no negociables, especialmente rostros visibles, magia central y restricciones memoriales.
3. Marcar los documentos y outputs históricos como `LEGACY` o moverlos a archivo; no mantener títulos ambiguos como `final`, `current` o `v3 aprobado`.
4. Generar un micro-lote revisable en una carpeta versionada aislada.
5. Hacer QA visual y actualizar este documento antes de escalar la generación.
